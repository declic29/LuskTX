# Vérifier et réviser un document

## L'orthographe et la grammaire

Lusk Texte souligne les fautes pendant la frappe : en rouge pour l'orthographe, autrement pour la grammaire.

- **Clic droit** sur un mot souligné : choisissez une suggestion, **Ignorer**, **Ignorer tout** ou **Ajouter au dictionnaire**.
- **Révision › Orthographe et grammaire** vérifie tout le document, faute par faute.
- **Révision › Langue** choisit la langue de vérification du texte sélectionné. La langue en cours s'affiche aussi dans la barre d'état.
- **Fichier › Options › Vérification** règle la correction automatique et indique pour quelles langues un dictionnaire est installé.

Les dictionnaires **français** (Dicollecte) et **breton** (An Drouizig) sont intégrés à Lusk Texte : ils fonctionnent tout de suite, sans rien installer. Pour écrire en breton, sélectionnez le texte puis choisissez **Breton** dans **Révision › Langue** ; un livre dont la langue est le breton (Mode Livre) est vérifié en breton automatiquement. Pour d'autres langues, Lusk Texte utilise un dictionnaire Hunspell installé sur l'ordinateur (par LibreOffice, par exemple) ; sans dictionnaire, la langue n'est pas vérifiée.

## Compter les mots et améliorer le style

- Le **nombre de mots** s'affiche en permanence dans la barre d'état ; **Révision › Nombre de mots** donne le détail (caractères, paragraphes, lignes…).
- **Thésaurus** propose des synonymes du mot sélectionné.
- **Lire à voix haute** fait lire le texte par la voix de l'ordinateur : pratique pour repérer les phrases maladroites.

## Les commentaires

1. Sélectionnez le passage concerné.
2. Cliquez sur **Révision › Nouveau commentaire** et tapez votre remarque.
3. Les commentaires apparaissent dans la marge, avec le nom de leur auteur. On peut y répondre, les résoudre ou les **supprimer**.

Le nom affiché est celui réglé dans Fichier › Options › Général.

## Le suivi des modifications

Idéal pour relire un document à plusieurs :

1. Activez **Révision › Suivi des modifications**.
2. Toutes les insertions, suppressions et changements de mise en forme sont désormais marqués en couleur, avec leur auteur.
3. Pour finaliser, passez d'une modification à l'autre avec **Suivant** / **Précédent** et choisissez **Accepter** ou **Refuser**.

Le menu **Afficher les marques** choisit ce qui est visible (Toutes les marques, Aucune marque, Original). Le **Volet Révision** liste toutes les modifications.

**Comparer** montre les différences entre deux versions d'un même document.

## Protéger un document

**Révision › Protection** permet de **restreindre la modification** (par exemple, autoriser seulement les commentaires). **Fichier › Informations › Protéger le document › Chiffrer avec un mot de passe** empêche toute ouverture sans le mot de passe. Conservez-le précieusement : sans lui, personne ne peut rouvrir le document, Lusk Texte compris.
