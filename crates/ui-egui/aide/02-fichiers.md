# Créer, ouvrir et enregistrer

## Créer un document

- **Fichier › Nouveau** propose un **Document vierge** et des **modèles** (lettre, CV, rapport…).
- Les modèles que vous avez enregistrés vous-même apparaissent sous **Personnel**.

## Ouvrir un document

- **Fichier › Ouvrir › Parcourir…** ouvre la fenêtre de Windows pour choisir un fichier.
- La liste **Récents** affiche les derniers documents ouverts : un clic suffit pour les rouvrir.
- Lusk Texte ouvre les fichiers Word (.docx, .doc, .dotx, .docm), OpenDocument (.odt), RTF, texte (.txt), Markdown (.md) et HTML.

## Enregistrer

- **Enregistrer** garde le document à son emplacement actuel.
- **Fichier › Enregistrer sous › Parcourir…** permet de choisir un dossier, un nom et un format.
- Le format conseillé est **Word (.docx)** : il est lu par la plupart des traitements de texte, dont Microsoft Word et LibreOffice.
- **Enregistrer comme modèle Word** crée un modèle (.dotx) que vous retrouverez dans Fichier › Nouveau › Personnel.

## Enregistrer sur OneDrive

Si OneDrive est installé sur votre ordinateur, un bouton **OneDrive** apparaît dans **Fichier › Ouvrir** et **Fichier › Enregistrer sous**. Il affiche directement le contenu de votre espace OneDrive :

1. Cliquez sur **OneDrive** dans la page Ouvrir ou Enregistrer sous.
2. Choisissez un dossier puis un fichier (pour ouvrir) ou tapez un nom (pour enregistrer).
3. Validez : Windows se charge d'envoyer le fichier sur votre espace en ligne.

Si vous avez un compte OneDrive personnel et un compte professionnel, un bouton s'affiche pour chacun.

## L'enregistrement automatique

Une fois le document enregistré une première fois, activez **Enregistrement automatique** dans la barre de titre : chaque modification est alors enregistrée sans que vous ayez à y penser. Le réglage se trouve aussi dans **Fichier › Options**, rubrique Enregistrer.

## Récupérer un document non enregistré

Si Lusk Texte s'est fermé brutalement, il propose au démarrage suivant de **récupérer** les documents qui n'avaient pas été enregistrés. Vous les retrouvez aussi dans **Fichier › Récupérer**.
