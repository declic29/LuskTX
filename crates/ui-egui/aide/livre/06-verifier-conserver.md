# Vérifier et conserver le livre

## Le contrôle qualité

Onglet **Livre › Contrôle qualité**, ou l'onglet **Qualité** du panneau Livre. Lusk Texte relit tout le livre et sa mise en page, et liste :

- les **pages blanches** qu'aucun début de chapitre n'explique, les **lignes veuves et orphelines**, les **titres seuls en bas de page** ;
- les **images** trop peu définies pour l'impression (moins de 300 ppp à leur taille dans le livre) ou sans description pour le livre numérique ;
- les **polices** absentes de l'ordinateur (remplacées dans le PDF) ou sans vrai gras ou italique ;
- les **marges** et le **format** qui diffèrent des réglages du livre, le **sommaire** qui n'est plus à jour ;
- les **titres** vides, les niveaux sautés, les paragraphes qui ressemblent à un titre sans en avoir le style ;
- les **paragraphes vides** en série, les **doubles espaces** et la **typographie française** : espaces insécables avant « ; : ! ? » et dans les guillemets, apostrophe ’, guillemets « », points de suspension …

Les problèmes sont classés en **erreurs** (rouge), **à vérifier** (orange) et **conseils** (bleu-vert). Cliquez un problème pour y aller. **Rien n'est modifié sans votre accord** : le bouton **Corriger** applique la correction proposée, **Tout corriger** celles d'une catégorie, et **Ctrl+Z** les annule. Relancez l'analyse après vos modifications.

## L'historique des versions

L'onglet **Versions** du panneau Livre (ou **Livre › Versions**) garde des copies complètes du livre **sur votre ordinateur seulement** :

- donnez un nom (« avant relecture ») et cliquez **Enregistrer** pour garder le livre tel qu'il est ;
- une version est aussi gardée **à chaque enregistrement** du livre (les 30 dernières ; les versions que vous avez nommées ne sont jamais supprimées sans vous) ;
- **Ouvrir** ouvre une version dans un nouveau document : le livre en cours ne change pas, vous pouvez comparer ou recopier un passage ;
- **Supprimer…** demande confirmation.

Les versions sont rangées dans le dossier des réglages de Lusk Texte (sous Windows : `%APPDATA%\LuskTexte\Versions`).
