# Structurer le livre

## Le panneau Livre

L'onglet **Plan** du panneau liste les éléments du livre dans l'ordre, avec le **nombre de mots** de chacun et le **total** du livre.

- **Cliquer** sur un élément : y aller.
- **Double-cliquer** : le renommer (Entrée pour valider, Échap pour annuler).
- **Glisser-déposer** : le déplacer avec tout son contenu. Un chapitre emporte ses sous-chapitres, une partie ses chapitres. Le texte n'est jamais recopié : il ne peut pas se perdre en route.
- **Clic droit** : Monter, Descendre, Ajouter un sous-chapitre, Supprimer. La suppression demande toujours confirmation, et **Ctrl+Z** l'annule.

Les boutons **+ Chapitre**, **+ Partie**, **+ Sous-chapitre** et le menu **Insérer** ajoutent des éléments là où un livre les attend.

## Pages liminaires et fin d'ouvrage

Le menu **Insérer** du panneau et l'onglet **Livre** ajoutent :

- avant le texte : **page de titre**, **dédicace**, **épigraphe**, **préface**, **avant-propos** ;
- après le texte : **remerciements**, **bibliographie**.

Chaque élément se place automatiquement au bon endroit : la dédicace après la page de titre, la bibliographie à la fin, etc.

## Les titres font la structure

Un chapitre est un paragraphe au style **Titre 1**, un sous-chapitre un paragraphe au style **Titre 2**. C'est ce qui alimente le panneau, le sommaire, les titres courants, les signets du PDF et la table des matières du livre numérique. Un titre tapé en gras sans style n'est pas un titre : le contrôle qualité vous le signale.

## Le sommaire

**Livre › Sommaire** insère une table des matières avec les numéros de page. Après des modifications, mettez-la à jour depuis le même groupe ; le contrôle qualité vous prévient si elle n'est plus à jour.
