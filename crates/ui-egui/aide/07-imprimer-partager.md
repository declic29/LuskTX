# Imprimer, exporter et partager

## Imprimer

1. Cliquez sur **Fichier › Imprimer**.
2. Vérifiez l'**aperçu** à droite, choisissez l'imprimante, le nombre de copies et les pages à imprimer.
3. Cliquez sur **Imprimer**.

## Exporter en PDF

Le PDF conserve exactement la mise en page et se lit sur tous les appareils : c'est le bon format pour envoyer un document qui ne doit pas être modifié.

1. Cliquez sur **Fichier › Exporter**.
2. Choisissez **PDF**, puis l'emplacement et le nom du fichier.

D'autres formats sont proposés dans la même page : OpenDocument (.odt), RTF, HTML, texte brut, Markdown, image…

Avant d'envoyer un document, les commandes **Vérifier l'accessibilité** et **Vérifier le document** (à retrouver avec la zone Rechercher de la barre de titre) signalent les problèmes de lecture et les informations à retirer : commentaires, modifications suivies, données personnelles.

## Le publipostage

Le publipostage crée une série de lettres, d'enveloppes ou d'étiquettes personnalisées à partir d'une liste (nom, adresse…).

1. **Publipostage › Démarrer la fusion et le publipostage** : choisissez Lettres, Enveloppes ou Étiquettes.
2. **Sélectionner les destinataires** : **Utiliser une liste existante…** (fichier Excel, CSV, OpenDocument…) ou **Entrer une nouvelle liste…**. **Modifier la liste des destinataires** permet de trier, filtrer ou exclure certaines personnes.
3. Rédigez le document et placez les informations variables avec **Insérer un champ de fusion**, **Bloc d'adresse** ou **Ligne de salutation**.
4. **Aperçu des résultats** montre le document pour chaque destinataire ; **Vérifier les erreurs** repère les problèmes.
5. **Terminer et fusionner** : **Modifier les documents individuels…** (un nouveau document avec toutes les lettres) ou **Imprimer les documents…**.
